# فري لاين — Free Line

الموقع التعريفي لشركة **فري لاين للشحن والتخليص الجمركي**: شحن بري وجوي وبحري، جزئي وحاويات كاملة، من تركيا والإمارات والصين ودول الخليج وأوروبا إلى سوريا، مع تخليص جمركي وتوصيل من الباب للباب.

## المزايا

- صفحة واحدة بالعربية (RTL)، متجاوبة مع الجوال والحاسوب.
- خريطة خطوط شحن متحركة (طائرات وحاويات تتجه إلى سوريا) ومشهد شحن متحرك: طائرة شحن، شاحنة، ورافعة ميناء.
- نموذج طلب عرض سعر يتحقق من الحقول ثم يفتح واتساب برسالة جاهزة.
- تحترم إعداد «تقليل الحركة» في النظام، وتدعم التنقل بلوحة المفاتيح.
- بدون أي أدوات بناء: HTML وCSS وJavaScript فقط.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
npx serve -l 4173 .
```

## تغيير رقم واتساب

في أعلى `js/main.js`:

```js
var WHATSAPP_NUMBER = '963991777173';   // صيغة دولية بدون + أو فراغات
var PHONE_DISPLAY  = '+963 991 777 173';
```

## هيكل المشروع

```
index.html        الصفحة
css/style.css     التنسيق والحركة
js/main.js        واتساب، القائمة، نموذج عرض السعر
images/           الشعار والأيقونات وصورة المشاركة
```
