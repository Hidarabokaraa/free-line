# فري لاين — Free Line

الموقع التعريفي لشركة **فري لاين للشحن والتخليص الجمركي**: شحن بري وجوي وبحري، جزئي وحاويات كاملة، من تركيا والإمارات والصين ودول الخليج وأوروبا إلى سوريا، مع تخليص جمركي وتوصيل من الباب للباب.

## المزايا

- صفحة واحدة بالعربية (RTL)، متجاوبة مع الجوال والتابلت والحاسوب.
- كرة أرضية منقّطة تفاعلية (Canvas) تُظهر خطوط الشحن إلى سوريا مع طائرات متحركة، تُدار بالسحب وتقترب من سوريا عند التمرير.
- شاشة تحميل، عناوين تظهر كلمة كلمة، شريط مدن متحرك، وتمرير ناعم (Lenis).
- الخدمات بتمرير أفقي مثبّت مع ستة مشاهد متحركة (شاحنة، طائرة، سفينة، شحن جزئي، حاوية، ختم جمركي).
- خريطة خطوط تفاعلية بكاميرا تنتقل إلى الخط المختار، ومسار «كيف نعمل» تتحرك فيه شاحنة مع التمرير.
- نموذج عرض سعر مع معاينة مباشرة لرسالة واتساب داخل هاتف.
- تحترم إعداد «تقليل الحركة»، والمحتوى يبقى كاملاً حتى لو لم تُحمَّل مكتبات الحركة.
- المكتبات: GSAP وScrollTrigger وLenis من jsDelivr. بيانات اليابسة مولّدة من Natural Earth في `js/geo-data.js`.

## التصميم السابق

التصميم الأول محفوظ في الوسم `design-v1` والفرع `backup/design-v1`. لاسترجاعه:

```bash
git checkout design-v1 -- .
```

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
npx serve -l 4173 .
```

## تغيير رقم واتساب

في أعلى `js/main.js`:

```js
var WHATSAPP_NUMBER = '963991777173';   // صيغة دولية بدون + أو فراغات
var PHONE_DISPLAY  = '+963 991 777 173';
```

## هيكل المشروع

```
index.html        الصفحة
css/style.css     التنسيق والحركة
js/main.js        الحركة، واتساب، القائمة، نموذج عرض السعر
js/globe.js       الكرة الأرضية وخريطة الخطوط
js/geo-data.js    نقاط اليابسة للخرائط
images/           الشعار والأيقونات وصورة المشاركة
```
